# Red Panda Publications

Static site served by Vercel (no build step, see `vercel.json`):

- `/` — the Red Panda Publications landing page and showroom
- `/studio/` — Red Panda Studio, the book-making tool (preview with a sample book; uploads need the Red Panda Studio server, not deployed yet)

Source of truth: the `redword` project (`apps/web/preview`). The previous Next.js site is in this repo's history before this commit.
